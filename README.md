## 🚢 How to Deploy on GitHub Pages (Step-by-Step)

### Method 1: Via GitHub Web Interface (Easiest)
1. Go to [GitHub.com](https://github.com) and create a **New Repository** (e.g., `aviraaj-digitech` or `<your-username>.github.io`). Set it to **Public**.
2. Upload all the files and folders from this directory (`index.html`, `privacy.html`, `terms.html`, `robots.txt`, `sitemap.xml`, `CNAME`, `css/`, `js/`, `assets/`).
3. Click on repository **Settings** ⚙️ -> **Pages** (in the left sidebar).
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your website will be live in 1 minute! 🎉

## 🌐 How to Connect Your Custom Domain (`aviraajdigitech.com`)

The `CNAME` file in the root is already pre-configured with `aviraajdigitech.com`.

### DNS Settings (In GoDaddy / Hostinger / Namecheap / Cloudflare):
Add the following DNS records in your domain provider dashboard:

1. **A Records** (Pointing to GitHub Pages IPs):
   - Type: `A` | Host / Name: `@` | Value: `185.199.108.153`
   - Type: `A` | Host / Name: `@` | Value: `185.199.109.153`
   - Type: `A` | Host / Name: `@` | Value: `185.199.110.153`
   - Type: `A` | Host / Name: `@` | Value: `185.199.111.153`

2. **CNAME Record** (For `www`):
   - Type: `CNAME` | Host / Name: `www` | Value: `<YOUR_GITHUB_USERNAME>.github.io`

3. In GitHub Repository **Settings** -> **Pages** -> **Custom domain**, enter `aviraajdigitech.com` and check **Enforce HTTPS**.
